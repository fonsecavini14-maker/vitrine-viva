# Vitrine Viva

Repositório do site da Vitrine Viva. O site ainda não começou; por enquanto está aqui o design system.

## Design system

- `design-system/index.html`: documentação completa (logo, cores, tipografia, espaçamento, bordas, sombras, componentes e tokens). Abra no navegador.
- `design-system/tokens.css`: as variáveis CSS (`--vv-*`) prontas para importar no site.

Regras principais:

- Fonte: Sora (400, 500, 600, 700). JetBrains Mono só para código.
- Coral do logo `#E8461F` no logo, ícones e títulos grandes. Botões e links usam `--vv-coral-strong` (`#C2391A`) para passar no contraste AA.
- Coral sobre fundo marinho usa `--vv-coral-bright` (`#FF6A45`).
- Espaçamentos sempre da escala de 4 px (`--vv-space-*`).
